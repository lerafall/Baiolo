# Spark Nest

Catch falling star-sparks in your nest, dodge moths, clear waves, unlock trail colors — a compact Baiolo arcade with score attack and local unlocks.

## How to zip for Baiolo

Zip the **contents** of this folder so the archive root contains `index.html`, `thumb.png`, and `cover.png` (not a nested parent folder).

## Baiolo metadata

- **Title:** Spark Nest
- **Tagline:** Catch sparks. Dodge moths. Nest the night sky.
- **Category:** Game
- **Tags:** arcade, catch, cozy, mobile

## Why come back tomorrow?

Beat your best score, earn stars toward new nest trails, and chase the daily sky seed for a fresh wave pattern.

## Creator note

- **Core loop:** Drag the nest · catch gold sparks · avoid moths · build combos
- **Replay hook:** Escalating waves, boss “Storm Moth”, one-more-run after a near miss
- **Return hook:** Best score + stars unlock trail cosmetics (localStorage)
- **Sticky:** Instant clarity, juicy feedback, visible progress bar to the next unlock
