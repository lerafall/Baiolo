# Starfall Garden

Fantasy casual puzzle-arcade for Baiolo. Aim a tiny falling star through a floating night garden, bounce soft leaves, slip violet portals, and bloom the crystal flower.

## Design direction

- **Visual:** Twilight indigo night, mint leaves, rose thorns, gold starlight, cyan crystal bloom. Layered nebula + pollen parallax, soft glows — art-directed, not prototype-raw.
- **Core loop:** Drag to aim → release to launch → bounce / portal / collect → reach crystal flower.
- **Juice:** Trail, impact particles, soft shake, flash, celebratory bloom burst, level card transitions.
- **Obstacle language:** Mint leaf = safe bounce · Rose thorn = gentle reset · Violet/cyan rings = portal · Gold shards = optional lights · Crystal flower = goal.
- **UI:** Dark glass pills, gradient CTA, short level purpose cards.

## Levels (8)

1. First Light — direct shot  
2. Leaf Bounce — bounce leaf  
3. Soft Thorns — avoid / reset  
4. Gather Glow — collectibles  
5. Portal Gate — teleport  
6. Turning Leaf — rotating platform  
7. Cascade Path — multi-bounce  
8. Starfall Finale — combined skills  

## Play

Open `index.html` in a browser, or from Baiolo: `/demos/starfall-garden/index.html`.
