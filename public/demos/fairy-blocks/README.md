# Fairy Blocks

Classic falling-block puzzle for Baiolo — Tetris-inspired mechanics wrapped in a premium fairy-tale look.

## Art direction

- **Mood:** Soft night-garden fantasy; crystal blocks that glow, never neon-noise.
- **Readability rules:** High-contrast cell fills + subtle rim light; ghost piece = translucent outline only; board gutters stay dark so shapes scan fast; max 7 distinct hues, never similar neighbors on same piece.
- **UI:** Rounded glass pills, child-friendly touch pads, minimal text — teach by playing.

## Color system (per world)

| World | Sky | Accents | Clear FX |
|-------|-----|---------|----------|
| Moon Garden | indigo / mint | lilac, gold | soft petal burst |
| Candy Cloud | rose cream | pink, peach | sugar sparkles |
| Crystal Forest | deep teal | emerald, cyan | shard shimmer |
| Aurora Castle | violet night | aurora green/pink | ribbon sweep |

## Worlds

1. **Moon Garden** — stages 1–2  
2. **Candy Cloud** — stages 3–4  
3. **Crystal Forest** — stages 5–6  
4. **Aurora Castle** — stages 7–8 · then Endless  

## Stage progression (8 + endless)

1. Slow intro · clear 2 lines  
2. Soft speed-up · 4 lines  
3. Candy world · 6 lines  
4. Faster drops · 8 lines  
5. Forest · 10 lines  
6. Combo focus · 12 lines  
7. Castle · 14 lines  
8. Pre-endless rush · 16 lines  
∞ Endless — rising gravity, score hunt  

## Feedback / juice

Ghost piece, lock flash, line-clear cascade + particles, combo toast, world transition wash, soft screen pulse on tetris (4-line).

## Controls

← → move · ↑ / X rotate · ↓ soft · Space hard · touch pads on mobile.
