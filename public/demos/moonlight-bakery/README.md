# Moonlight Bakery

Cozy fantasy micro-management for Baiolo. Run a magical night bakery for forest visitors — prepare pastries, bake them in glowing ovens, and serve the right order before patience fades.

## Art direction

- **Mood:** Warm night bakery under a soft moon; amber oven light against plum twilight.
- **Palette:** night `#1a0f2e`, cream `#fff7ed`, oven gold `#fbbf24`, frosting pink `#f9a8d4`, mint `#6ee7b7`, berry `#fb7185`.
- **Look:** Rounded glass panels, fairy lights, glowing ovens, soft particle flour dust — premium-playful, not prototype-raw.

## UI style

- Dark frosted HUD pills + warm gradient CTAs.
- Order bubbles above customers with clear pastry icons.
- Drag ingredients → prep → oven → serve tray.
- End-of-day summary with stars / coins / combo.

## Customers

| Guest | Order icons |
|-------|-------------|
| Bunny | Moon Bun |
| Fox | Berry Tart |
| Owl | Star Cookie |
| Hedgehog | mix |

## Products

1. **Moon Bun** — flour → prep → bake  
2. **Berry Tart** — flour + berry → prep → bake  
3. **Star Cookie** — flour + moon sugar → prep → bake  

## Core loop

Customer arrives with order → drag ingredients to prep → send to oven → collect pastry → drag/tap serve onto matching customer → combo if fast.

## Juice

- Oven shimmer & flour puffs  
- Serve sparkles + soft shake  
- Patience hearts drain visually  
- Combo toast + end-of-day star rating  

## Levels (bakery days)

1. First guest — one bunny, Moon Bun  
2. Busy counter — two guests  
3. Warm clock — patience meters  
4. Berry shelf — Berry Tart unlocks  
5. Flour sprite helper — auto-tips / speed  
6. Queue night — three guests  
7. Twin ovens — two bake slots  
8. Moon Festival finale — all recipes, twin ovens, queue
