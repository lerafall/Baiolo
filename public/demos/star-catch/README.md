# Star Catch

Tiny tap-to-catch stars game. Baiolo demo MVP.

## Zip for Baiolo

Zip these files so `index.html` is at the ZIP root:

- `index.html`
- `styles.css`
- `script.js`
- `thumb.jpg` / `cover.jpg` (screenshots for Baiolo cards)

## Baiolo metadata

- **Title:** Star Catch
- **Tagline:** Tap falling stars before they vanish.
- **Category:** Game
- **Tags:** arcade, tap, cozy, mobile
